# узкие места миграции «Медикаменте»

## Инфраструктура (🟠 Приоритет: ВЫСОКИЙ)

| Проблема                                    | Рекомендация                                                                                        | Срок     | Ответственный        |
|---------------------------------------------|-----------------------------------------------------------------------------------------------------|----------|----------------------|
| Старое оборудование не тянет новую нагрузку | Горизонтальное масштабирование: K8s кластер из 3+ нод, закупка новых серверов (64+ GB RAM, 8+ vCPU) | 3 недели | Технический директор |
| Сетевые каналы (1 Гбит/с → нужны 10 Гбит/с) | Апгрейд сетевого оборудования до 10 Гбит/с, настройка QoS для приоритетного трафика API             | 2 недели | Администратор сети   |
| Один сервер → не хватает под микросервисы   | Внедрение Kubernetes, разделение по namespaces, авто-масштабирование (HPA)                          | 4 недели | DevOps               |

## Данные (🔴 Приоритет: КРИТИЧЕСКИЙ)

| Проблема                                  | Рекомендация                                                                                                              | Срок     | Ответственный            |
|-------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|----------|--------------------------|
| Миграция 10+ лет Excel-файлов → БД        | Поэтапная миграция: сначала текущий год, затем исторические данные. Использовать ETL (Apache Spark) с валидацией чек-сумм | 6 недель | Бизнес-аналитик + DevOps |
| Дублирование данных (Excel + 1С)          | Определить source of truth (1С → PostgreSQL), настроить CDC (Debezium), дедупликацию                                      | 2 недели | DevOps                   |
| Нет единого формата (JPG, PDF, XLSX, DOC) | OCR для сканов, конвертация в PDF/A для архивов, структурированных данных — в JSON                                        | 3 недели | Разработчики             |
| Очистка PII перед загрузкой в Data Lake   | Внедрить Anonymization Engine (k-anonymity, l-diversity), токенизацию через Privacy Vault                                 | 3 недели | Аналитик + DevOps        |

## Интеграция (🟠 Приоритет: СРЕДНИЙ)

| Проблема                                       | Рекомендация                                                                                              | Срок     | Ответственный    |
|------------------------------------------------|-----------------------------------------------------------------------------------------------------------|----------|------------------|
| ККМ → OLE/TCP → замена на HTTPS                | Параллельный запуск: старый канал (OLE) + новый (TLS), затем отключение OLE. Тестирование фискализации    | 2 недели | Администратор 1С |
| Лаборатория → файлы на диск → переделка на API | Разработать API-адаптер, лаборатория продолжает класть файлы, адаптер забирает и отправляет в API Gateway | 3 недели | Разработчики     |
| 1С → файловый режим → клиент-сервер            | Миграция БД 1С в выходные, тестирование на копии, план отката                                             | 2 недели | Администратор 1С |
| AD → Keycloak (синхронизация паролей)          | Двунаправленная синхронизация LDAP, постепенный перевод пользователей, обучение входа через Keycloak      | 2 недели | DevOps           |

## Процессы (🟠 Приоритет: СРЕДНИЙ)

| Проблема                             | Рекомендация                                                                                 | Срок            | Ответственный        |
|--------------------------------------|----------------------------------------------------------------------------------------------|-----------------|----------------------|
| Downtime при миграции (24/7 клиника) | Blue-Green deployment, миграция в 3 этапа (ночные окна 02:00-06:00), резервные каналы записи | на всю миграцию | Технический директор |
| Ручные процессы → автоматизация      | CI/CD пайплайн (GitLab CI), Infrastructure as Code (Terraform), автоматические тесты         | 3 недели        | DevOps               |
| Бизнес-процессы не задокументированы | Аудит процессов, создание документации BPMN, утверждение с бизнес-заказчиком                 | 4 недели        | Бизнес-аналитик      |

## Персонал (🟡 Приоритет: НИЗКИЙ)

| Проблема                             | Рекомендация                                                                     | Срок            | Ответственный        |
|--------------------------------------|----------------------------------------------------------------------------------|-----------------|----------------------|
| Сотрудники не обучены новым системам | Обучение за 2 недели до запуска, запись видеоинструкций, тестирование            | 2 недели        | Бизнес-аналитик      |
| Сопротивление изменениям             | Change Management, вовлечение ключевых пользователей в пилот, демонстрация выгод | на всю миграцию | Технический директор |
| Не хватает DevOps/SRE инженеров      | Найм 2 DevOps + аутсорсинг на время миграции (K8s, Kafka, CI/CD)                 | 4 недели        | Технический директор |

## Безопасность (🔴 Приоритет: КРИТИЧЕСКИЙ)

| Проблема                                   | Рекомендация                                                                       | Срок     | Ответственный      |
|--------------------------------------------|------------------------------------------------------------------------------------|----------|--------------------|
| Утечка PII в процессе миграции             | Шифрование всех миграционных каналов (TLS 1.3), маскирование в логах, DLP контроль | 1 неделя | Администратор сети |
| Шифрование при передаче (TLS) не настроено | TLS everywhere: nginx/API Gateway как терминация, строгие cipher suites            | 1 неделя | DevOps             |
| Нет аудита доступа во время миграции       | Включить audit logging на всех этапах, Wazuh + ELK, алерты на аномалии             | 1 неделя | DevOps             |
